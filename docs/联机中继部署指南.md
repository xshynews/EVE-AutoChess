# 联机中继服务器 · 部署指南

目标：给 `net.cfg` 的 `[relay] server` 填一个公网 `地址:端口`，
让两个玩家（其中一方可能是手机）只交换 8 位房间码就能对战。

前提结论（2026-10-29 确认）：
- `eve_net_config` / `eve_udp_relay` 都支持**域名**，不用改代码；
- 中继是单文件 Node 脚本（`tools/relay/eve_relay_server.js`），零依赖，2核2G 绰绰有余；
- 自走棋是回合制，流量极小（每局几十 KB 级），免费额度完全够。

---

## 方案 A：阿里云轻量应用服务器（推荐 · 38 元/年）

**抢购要点（每天 10:00 / 15:00 两场秒杀）**
- 入口：https://www.aliyun.com/daily-act/ecs/activity_selection 首板块「38元抢轻量应用服务器」
- 条件：账号**实名** + 该实名主体从未买过任何阿里云付费产品（买过再退款也算老用户）
- 提前几分钟进页面候着；未抢到同配置 68 元/年可直接买，不必等
- 38 元续费会涨到 68；打算用两年以上可对比 ECS 经济型 e（99 元/年，续费同价）

**配置怎么选**
- 2核2G / 40G ESSD / 200M 峰值带宽——对中继来说严重过剩，够了
- 地域选离玩家近的（华东/华北均可）
- 镜像选 **Ubuntu 22.04/24.04**（别选宝塔，用不上）

**部署（10 分钟）**
```bash
# 本机把两个文件传上去（IP 换成你的公网 IP）
scp tools/relay/setup_vps.sh tools/relay/eve_relay_server.js root@<公网IP>:/root/

# SSH 到服务器
ssh root@<公网IP>
bash /root/setup_vps.sh
```

**⛔ 最容易漏的一步**：轻量服务器控制台 → 防火墙 → 添加规则 →
**协议 UDP、端口 27100、策略允许**。系统内 ufw 脚本会自动放行，
但云控制台这层不放行的话，包照样进不来。

**验证**（本机）：
```bash
# 能收到中继回的空注册回包即通（Windows: 直接进游戏建房测试也行）
```

**填地址**：
- 调试阶段：写 `user://net.cfg`（`[relay] server="IP:27100"`），不用重新打包
- 发给玩家：填进 `scripts/net/eve_net_config.gd` 的 `BUILTIN` 常量后**重导出 APK/EXE**

## 方案 B：免费内网穿透（零成本，当天能用）

| 服务 | 免费额度 | UDP | 备注 |
| --- | --- | --- | --- |
| SakuraFrp（natfrp.com） | 2 条隧道 / 10Mbps / 5GB/月，签到加流量 | ✅ | 需实名；节点多 |
| OpenFrp | 2 条 / 12Mbps / 1GB/月，签到加流量 | ✅ | 大陆节点需实名，海外不用 |
| ChmlFrp | 4 条 / 8Mbps / 不限流量 | ✅ | 需实名，送免费域名 |

**选一个支持 UDP 的服务**（我们的中继走 UDP，TCP-only 的 NATAPP/花生壳免费版不行）。

**步骤（以 SakuraFrp 为例）**
1. 注册 + 实名，下载启动器
2. 建一条 **UDP 隧道**，选国内节点，本地端口指向你电脑上跑的中继
3. 本机跑中继，**端口必须和隧道的远程端口一致**（⚠️ UDP 隧道不做端口映射）：
   ```
   node tools/relay/eve_relay_server.js <远程端口>
   ```
4. `net.cfg` 填 `节点域名:远程端口`

**限制提醒**：免费档限速 10Mbps 对回合制足够，但流量月清零、隧道可能过期重建，
**适合先跑通真人联机测试，正式发包还是上方案 A**。

---

## 通用注意事项

1. **端口三者一致**：net.cfg 的端口 = 中继监听端口（= 隧道远程端口），不一致 ⇒ 包发出去没人接。
2. 手机当房主依赖中继心跳（1.5s 一次），中继挂了 ⇒ 大厅建房后对方永远连不上。
3. 改完 `BUILTIN` 记得 `verify_net_config`（如有）+ 重导出两个包，V0.14.8 当前包内是空地址。
