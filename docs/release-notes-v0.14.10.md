Windows / Android 安装包（整包）。**本版起客户端内置热更新**：以后的小改动（脚本 / 数据 / 界面 / 数值）不用重装，启动时自动下载并校验。

## 下载

| 平台 | 文件 |
|---|---|
| Windows | `EVE-AutoChess-V0.14.10.exe`（单文件，直接运行） |
| Android | `EVE-AutoChess-V0.14.10.apk`（arm64-v8a，`versionCode 19`） |

## 关于热更新

- 启动时读取版本清单，发现新版本就下载补丁包（约 1 MB），**校验 SHA256 后**才挂载；校验不过或下载失败则照常用本地版本进游戏。
- 补丁包不阻塞启动、失败不报错、坏包连续 3 次进不到主菜单会自动删除回退。
- 可热更范围：`scripts/`、`data/`、界面与数值。**美术资源（模型 / 贴图 / 音频）和引擎本体不可热更**，那类更新仍需装整包。
- 历史补丁包见仓库里 `hotfix-*` 标签的 Release。
