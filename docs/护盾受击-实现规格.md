# 护盾受击 · 实现规格（Blender look-dev → Godot 着色器）

> 基准样式：`refs/vfx_v16.mp4`。本文件是把它搬进 Godot 的规格说明。
> 核心：**椭球护盾 + 球面投影的翻页水花 + 角向门限 + 时间衰减**。

## 1. 护盾几何

```
half  = 船体包围盒半尺寸 (x, y, z)      # 世界单位
axes  = (half.x * 1.16, half.y * 1.10, half.z * 1.80)
center = 船体包围盒中心
```

- 高度 ×1.8 的原因：舰船是扁的，等高会贴着甲板。
- Godot：`MeshInstance3D` + `SphereMesh`，`scale = axes`，位置 `center`。

## 2. 受击方向

```
n_imp = normalize((impact_world - center) / axes)   # 单位球空间
t1 = normalize(cross(n_imp, up));  t2 = cross(n_imp, t1)
```

## 3. 贴花投影（片元着色器里）

```glsl
vec3 p = (VERTEX - center) / axes;      // 单位球空间
vec3 v = p - n_imp;
vec2 uv = 0.5 + vec2(dot(v, t1), dot(v, t2)) / (2.0 * R);
float circ = 1.0 - smoothstep(0.47, 0.50, length(uv - 0.5));
float gate = smoothstep(0.38, 0.72, dot(normalize(p), n_imp));
vec4 tex = texture(atlas, uv / 8.0 + frame_offset);   // 8×8 图集
float a = tex.a * circ * gate;
```

## 4. 时间轴（32fps，共 72 帧）

| 帧 | 事件 | 参数 |
|---|---|---|
| 1–3 | 光束生长 | 长度 0→100% |
| 4–8 | 命中极亮点 | 尺寸 7→13→9，亮度 30 |
| 5–8 | 水花起爆 | R 0.05 |
| 8–24 | 水花扩散 | R 0.05→0.27 |
| 24–54 | 衰减 | 发光 8→1.2 |
| 54–70 | 收尾 | 发光→0 |

## 5. 参数表

| 参数 | 值 |
|---|---|
| 图集 | 4096×4096，8×8，单帧 512，64 帧 |
| 帧率 | 32fps（与游戏 `shield_effect.fps` 一致） |
| R 范围 | 0.05 → 0.31（单位球半径 = 1） |
| 圆盘遮罩 | 0.47–0.50 |
| 角向门限 | 0.38–0.72（`dot`） |
| 发光 | 峰值 12（HDR，靠 Bloom 溢出） |
| 混合 | 加法 |

## 6. Godot 落地要点

1. `ShaderMaterial` 挂在椭球 `MeshInstance3D` 上，uniform：`impact_dir`、`R`、`frame`、`strength`。
2. 翻页图集用 `atlas_region` 计算，不要每帧换贴图。
3. 角向门限用 `smoothstep`，**不要**用 `step`（会产生硬边）。
4. Bloom 走 `WorldEnvironment` 的 glow，阈值 ~1.0，强度 0.8。
5. 每艘船一张材质实例（R、impact_dir 不同），不要共用。

## 7. 验收

- [ ] 受击点亮度最高，向外衰减；
- [ ] 水花只出现在受击面，背面无残留；
- [ ] 水花贴着椭球弧度，斜视角不穿帮；
- [ ] 72 帧内完全消失，不留常亮斑。

### 8.4 已知坑（踩过的）

1. **`look_at` 必须在 `add_child` 之后**，否则 "Node not inside tree"；
2. **shader 数组参数未初始化时 `get_shader_parameter` 返回 null**，必须先在 `_ready` 里 push 一次默认数组；
3. **shader 里 `vec3 col` 会与内置符号冲突**（Redefinition of 'col'），改用 `fire_rgb`；
4. **贴图要先被编辑器导入**（`godot --headless --editor --quit`），运行时才 `load()` 得到。

## 9. 贴花式护盾（2026-10-20 晚，替换第 8 节的球面波方案）

### 9.1 为什么换

第 8 节的球面波是「整壳发光的亮环」，看起来像玻璃罩在脉动，**不呈现护盾形状**。
参考 EVE 毒蜥级的炮击受击，正确读法是：

> 命中点附近一块**椭圆区域**被点亮，这块区域**贴着壳的曲率弯折** —— 正因为它是贴在壳上的，才让人"看见"护盾。

### 9.2 实现

| 要素 | 做法 |
|---|---|
| 几何 | 每个爆点克隆一份壳网格（共享几何、独立材质） |
| UV | 世界坐标 → 命中点切平面 → 归一化 |
| 切平面基 | `t1` 固定沿船体长轴（世界 X），避免船顶法线接近 +Z 时基退化 |
| 遮罩 | 椭圆 1.45 : 1，横轴沿船长 |
| 门限 | 不用角向门限（椭球法线易被拉偏），靠壳自身遮挡 |
| 图集 | 64 帧 8×8，`frame` uniform 推进 |

### 9.3 参数（已实测，L = 船体半长）

| 参数 | 值 |
|---|---|
| `decal_radius` | `L * 0.04` → `L * 0.30`（1.1 秒内） |
| `aspect` | 1.45 |
| `intensity` | 2.2 → 0 |
| 帧推进 | 0 → 50（对应图集前 50 帧） |
| 寿命 | 1.1 秒 |

### 9.4 文件

| 文件 | 作用 |
|---|---|
| `scripts/visual/fx_shield_decal.gdshader` | 贴花着色器 |
| `scripts/visual/shield_decal_test.gd` | 测试场景（四发） |
| `scenes/shield_decal_test.tscn` | 入口 |
| `assets/vfx/advent_shield_impact_atlas.png` | 水花图集（**必须导入**） |

### 9.5 踩坑记录（新增）

5. **图集缺失不报错**：`atlas` 为 null 时 `texture()` 返回白纹理，alpha 恒 1 → 整个壳被点亮成白团，极易误判为着色器写错。**先确认 `ResourceLoader.exists()`**。
6. **切平面投影要去法线分量**：`rel -= n * dot(rel, n)`，否则贴花被壳面拉平、纹理糊成一片。
7. **门限用位置向量比法线稳**（椭球非等比缩放时法线会被拉偏），但最稳的是不用门限。

## 10. 最终定稿（2026-10-20 夜）

**目标：护盾无形，只在受击时显现形状。**

### 10.1 核心机制

命中点周围一块**椭圆水花**贴在壳面上，随椭球曲率弯折 —— 这是"看见形状"的唯一来源。
护盾本体平时完全不可见（无材质或全透明）。

### 10.2 关键公式（Blender 与 Godot 通用）

```
# 归一化到单位球空间（必须！）
unit_pos  = world_pos  / shell_axes
unit_hit  = hit_center / shell_axes
rel       = unit_pos - unit_hit

# 投到切平面（去掉法线分量）
n         = normalize(hit_normal / shell_axes)
rel      -= n * dot(rel, n)

# 椭圆 UV
du = dot(rel, normalize(tangent_u / shell_axes)) / (decal_radius * aspect)
dv = dot(rel, normalize(tangent_v / shell_axes)) / decal_radius
uv = vec2(du, dv) * 0.5 + 0.5
```

| 参数 | 值 | 说明 |
|---|---|---|
| 椭球半轴 | 182.7 / 91.7 / 26.3 | 启示号（船体半长 180） |
| 椭球比例 | 1.015 / 0.509 / 0.146 | × 船体半长 |
| `aspect` | 1.45 | 横轴沿船长 |

### 10.5 六个坑（跨引擎）

1. 贴花压扁 → 必须进单位球空间
2. 克隆丢缩放 → 显式继承 object.scale
3. 发射时间轴错位 → 各发独立衰减窗口
4. Godot 图集缺失静默失败 → 先 `ResourceLoader.exists()`
5. GDScript `var u := lerp()` 推断 Variant → 显式类型
6. shader 保留字 `col` → 改 `decal_rgb`
