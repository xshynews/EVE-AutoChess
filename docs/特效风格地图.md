# 太空科幻战斗特效 · 风格地图

> 用途：选型手册。你说的「像 EVE 那种、不要卡通」，本质是**三个维度同时选对**，
> 只挑「特效类型」是不够的。本文按维度拆开，最后给组合示例与片单。

---

## 0. 三个维度（风格 = 三者相乘）

| 维度 | 决定什么 | 选项 |
|---|---|---|
| **世界观质感** | 观众第一眼的「这是什么世界」 | 冷工业 / 电影级太空歌剧 / 舰队史诗 / 动漫机甲 / 街机卡通 / 复古像素 |
| **效果语言** | 战斗靠什么打、怎么反馈 | 光束 / 脉冲 / 磁轨 / 实弹 / 导弹 / 等离子 / 无人机 / 超级武器 |
| **镜头与后期** | 同样的特效，拍出来是史诗还是手游 | 长焦克制 / 手持临场 / 过曝爆闪 / 高速慢镜 / 无后期 |

⚠️ 卡通感 90% 来自第三维和第一维，不是来自「用了什么武器」。

## 1. 六个风格家族

### A. 冷工业硬科幻（**EVE 在这里**）
- 代表作：EVE Online / EVE Echoes、Elite Dangerous、Star Citizen、Nexus: The Jupiter Incident
- 气质：金属、低饱和、大量暗部、UI 像仪表盘；爆炸是「工程事故」不是「烟花」
- 光比：高（亮部很亮、暗部很黑），饱和度低
- 描边：无。后期：轻 bloom + 轻微色差，不做漫画滤镜
- 风险：容易做得「灰扑扑」——需要靠光源方向和金属高光提气

### B. 电影级太空歌剧（Villeneuve 系）
- 代表作：Dune (2021)、Interstellar、The Expanse、2001
- 气质：巨大尺度、尘埃、沉默、慢；镜头长焦压缩，飞船在画面里很小
- 光比：极高，常常逆光剪影；饱和度极低（沙色/灰蓝）
- 适合：开场、BOSS、剧情演出
- 风险：节奏慢，不适合自走棋这种高频战斗

### C. 舰队史诗
- 代表作：Homeworld 1–3、Sins of a Solar Empire、Battlefleet Gothic、银河英雄传说
- 气质：编队、齐射、成排的光束与爆炸；画面信息密度高
- 光比：中高，色彩比 A 更艳一点
- 适合：以「阵型」为核心的玩法——你的 4 派系羁绊正合适

### D. 动漫/机甲
- 代表作：高达 UC、Macross、Eureka Seven
- 气质：高饱和、强轮廓光、能量武器有「刃」的形态、爆炸是球状+十字光
- 风险：**最容易滑向卡通**，除非你明确要这个

### E. 街机/卡通风
- 代表作：云顶之弈、星际 2、绝大多数手游 SLG
- 特征：描边、渐变贴图、屏幕大抖、伤害数字弹跳、技能特效盖住单位
- 这是你要避开的区域——它的目的是「可读性优先于真实感」

### F. 复古/像素
- 代表作：FTL、星界边境
- 只在你想做「怀旧模式」时才考虑

## 2. 效果类型目录（真正要挑的东西）

### 2.1 主武器

| # | 类型 | 视觉特征 | 传达的信息 | 卡通风险 |
|---|---|---|---|---|
| 1 | **连续光束** | 核心纯白 + 外圈青/红辉光，有粗细渐变与闪烁 | 持续压制、能量武器 | 中（容易做成均匀发光的棍子） |
| 2 | **脉冲激光** | 短促弹丸、有飞行时间、命中炸开 | 节奏感、可预判 | 低 |
| 3 | **磁轨/质量加速** | 瞬间白线 + 冲击波环 + 长尾迹 | 穿甲、重火力、后坐 | 低 |
| 4 | **实弹/近防炮** | 曳光弹串、有散布、弹壳/弹幕 | 密集、廉价、绝望感 | 低（**最提真实感**） |
| 5 | **导弹/鱼雷** | 烟迹、机动转弯、近炸 | 追踪、威胁感 | 中（烟迹容易假） |
| 6 | **等离子/球状能量** | 缓慢、粘稠、边缘不规则 | 恐怖、异种科技 | 高 |
| 7 | **无人机/舰载机** | 小单位蜂群 | 数量感、编队 | 中 |
| 8 | **超级武器** | 全屏白闪 + 冲击环 + 残骸 | 终结技、演出高潮 | 中（容易变烟花） |

### 2.2 防御与命中反馈（**这块最容易被忽略，但最决定「过家家感」**）

- **护盾**：球面六边形/能量膜涟漪，命中点扩散衰减 —— EVE 的护盾波纹是标杆
- **装甲**：火花（方向沿法线）、熔渣、金属蒸发白烟
- **结构**：泄气白雾、火点蔓延、碎片剥落
- **点防拦截**：拦截弹近炸 + 碎片云
- **锁定/电子战**：锁定框抖动、干扰波纹（EVE 的锁定框很出彩）

> 判断标准：**命中必须改变被击中物的状态**（亮度、材质、烟雾、姿态）。
> 只在目标表面贴一个闪光贴图 = 过家家。

### 2.3 死亡与残骸

| 做法 | 观感 | 成本 |
|---|---|---|
| 一次性爆炸放大 | 廉价、手游感 | 低 |
| **分段**：闪光 → 解体 → 残骸漂移 → 二次爆炸 | 可信、有重量 | 中 |
| 反应堆殉爆：蓝白闪光 + 冲击环 + 电磁脉冲 | 史诗 | 中高 |
| 残骸场累积 | 战场「越打越脏」，真实感最强 | 低（复用模型） |

★ 你的「打捞」机制正好需要**残骸**——这是玩法与表现的双赢点。

### 2.4 环境
- 星云/尘埃：体积感 > 贴图感
- 小行星/残骸：**前景遮挡 = 尺度感的来源**
- 恒星逆光：最强的「史诗」开关，一个平行光就能做到
- 巨构（空间站/星门）：给画面一个「参照物」，船才会显得小

### 2.5 镜头与后期（**决定「像电影」还是「像页游」**）

| 手法 | 效果 | 风险 |
|---|---|---|
| 长焦压缩（FOV 15–25°） | 舰船显得巨大、有压迫感 | 视野窄，需要重新设计构图 |
| 手持微抖（0.2–0.5°） | 临场感 | 超过 1° 就晕 |
| hitstop（命中 3–6 帧停顿） | 打击感 | 多了像卡顿 |
| 爆炸过曝 2–3 档再回落 | 光的「重量」 | 需要 HDR + tonemap |
| 轻微色差 + 颗粒 | 镜头感 | 过量 = 廉价滤镜 |
| 运动模糊 | 速度感 | 移动端性能 |

## 3. 五条「不卡通」硬规则

1. **不描边**（outline 是卡通的第一特征）
2. **不用渐变贴图当主体**（发光必须来自光源 + bloom，而不是贴图自发光）
3. **所有光都要有衰减**（没有 falloff 的光 = 塑料）
4. **屏幕抖动 ≤ 0.5°**，且只在大事件（击毁/超级武器）
5. **UI 数字不弹跳、不描边、不用高饱和色**

## 4. 组合示例（三套可直接抄的配方）

### 配方 1：EVE 正统（推荐作为默认）
A 冷工业 + 1 连续光束 & 4 实弹 + 球面护盾涟漪 + 分段爆炸 + 长焦微抖
→ 关键词：克制、工程感、密集但不花

### 配方 2：舰队史诗（适合 BOSS / 羁绊满级）
C 舰队史诗 + 3 磁轨齐射 + 8 超级武器 + 残骸场 + 逆光
→ 关键词：阵型、齐射、压迫

### 配方 3：电影级演出（适合开场 / 通关）
B 太空歌剧 + 6 等离子 + 反应堆殉爆 + 极慢镜 + 低饱和
→ 关键词：沉默、巨大、敬畏
