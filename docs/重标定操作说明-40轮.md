## 三、操作表

### 选船
- 右侧列表点船（**中文名可搜**）
- `←` / `→` 翻上一艘 / 下一艘

### 转轴体（定朝向）
> **前提：鼠标必须先移到那根轴上**（高亮后该轴才解锁）

| 键 | 作用 |
|---|---|
| 裸 `W` / `S` | 选中轴 上下转 15° |
| 裸 `A` / `D` | 选中轴 左右转 15° |
| `Q` / `E` | 轴阵中心 前后平移 |
| `1` ~ `6` | 缩放**选中那根**轴 |
| 滚轮 | 整组缩放 |
| 拖红球/蓝球端点 | 伸缩该轴 |
| `R` | 全部重置 |

### 转船（船跟着手转，方便看清）
| 键 | 作用 |
|---|---|
| `Shift+W/S` | 船 上仰 / 下俯 |
| `Shift+A/D` | 船 左转 / 右转 |
| `Shift+Q` 或 `Shift+E` | 船 侧躺（绕 Z） |
| 右键拖 | 转船 |

### 确认 / 保存
| 键 | 作用 |

## 四、★ 怎么验证这工具没骗你

**按 `H`**，HUD 会显示锚点对账。它拿**你自己确认过的 3 艘船**反算：

| 锚点船 | 你何时确认的 | 工具必须算出 |
|---|---|---|
| `catalyst` 促进级 | 2026-09-26 实机裁决「不 FLIP 是对的」 | 舰艏世界方向 = **−Z（朝敌）** |
| `kestrel` 茶隼级 | 2026-09-26「没有肚皮朝天」 | 舰艏世界方向 = **−Z（朝敌）** |
| `slasher` 伐木者级 | 2023 判「舰艏=+Y」，与 kestrel 同构 | 舰艏世界方向 = **−Z（朝敌）** |

**全 ✅** ⇒ 工具显示的轴方向 = 游戏里的舰艏方向，可以放心用。
**出现 ❌** ⇒ 工具当场告诉你「**别信这个工具显示的方向**」，那就先别标，来找我查。

> 这一条是**不靠工具自证**的 —— 期望值来自你的历史裁决，不是工具自己算出来的。

## 五、HUD 上要看的三行

1. **`▣ 模型空间语义轴（SHIP_AXES 里存的）`** —— 游戏规则表里存的那个正值
2. **`▣ 世界方向（= 轴体画面 = 游戏里看到的）`** —— **标定只认这一行**
3. **`🧭 锚点对账`** —— 上面第四节那条

两行不同是**正常的**：本库 47 艘的 `AXIS_REMAP` 含一次 180°，它把模型轴翻到世界里去了。

## 六、怎么"真的进游戏"

**姿势表 ≠ 游戏生效。** 分两步：

1. 在工具里标好，按 `Enter` ⇒ 进 `pose_table.json`
2. 标完（或标一批）后，用 `--flush` 再启动一次工具：
   ```bash
   "C:/godot/Godot_v4.7.1-stable_win64_console.exe" \
     --path "F:/evezzq/eve自走棋918" res://tools/bow_box_launcher.tscn -- --flush
   ```
   ⇒ 这一步才把姿势表写进 `eve_ship_yaw.gd`
3. 然后跑一次 `--import`，让游戏读到新常量

> ⚠️ **默认不落盘**（保护：未经确认不改游戏源码）。
> ⚠️ 落盘时会**自动跳过 FLIP 冲突船**（那是双重 180° = 会变倒飞）。

## 七、其他启动开关

| 参数 | 作用 |
|---|---|
| （无参数） | 正常启动，**先归档旧表 + 清空**，不落盘 |
| `--keep-pose` | **跳过清空**（保留当前姿势表，想接着标时用） |
| `--flush` | 启动时把姿势表写进游戏规则表 |
| `--ids=id1,id2` | 只列这几艘（调试用） |
| `--self-test` | 无头自检 + 截图后退出 |
