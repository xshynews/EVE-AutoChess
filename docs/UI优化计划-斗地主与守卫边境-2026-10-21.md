## 2. 守则（沿用既定路线，⛔ 不另造一套）

1. **视觉语言**：直角、深色半透明、细边框、克制强调色。
   ⇒ ddz 自绘按钮 `圆角 8 → 0` 列入改动；不新增圆角卡片 / 赛博主题。
2. **手机档触控**：次按钮热区 **≥88×48**、主操作高 **≥48**、顶条/底栏 **≥64**。
3. **桌面端逐像素不变**：`verify_ui_scale` 第 3 段「桌面档位表 === `RECT_*`」是硬护栏。
4. **安全区**：左列从 `safe_left + MOBILE_EDGE` 起；⛔ 只挪一侧，居中带会压到侧列。
5. **⛔⛔ 高度不写死**：内容最小高度由**实测传入**（`_win_need_h` / `syn_need` 口径）。
   2026-10-20 教训：写死 280 在手机字号 **120%** 下必然失效（实机真实需求 364）。
6. **量数字必须在 1.20 档**：移动端默认字号 120%，本地探针默认 110% ⇒ 本地永远通过、实机永远重叠。
7. **i18n 冻结**：`EveText.LANGUAGE_ENABLED=false`；⛔ 不加 key、不动 `strings.csv` 行数。
   新文案一律 `T.t(key, 中文兜底)` 且复用既有 key。
8. **红线**：新面板必验「点下有反应」；`EveWindow` 不自动调 `_build_contents()`；
   暂停只 `set_paused()`；音量只 `EveAudio.set_volume()`。
9. **验收**：改动必进 `verify_*`，跑 `tools/run_verifies.sh`（18 套）；**失败计数 > 0 即失败**。
10. **真机流程**：导出 → `adb push` + `pm install`（⛔ `adb install` 实测会挂 20 分钟）
    → `pm clear com.evezzq.autochess` → 启动 → `screencap` 核对。

## 3. 分期计划

### ★ 阶段 0 · 比例基线（2026-10-21 用户追加，**优先于下面各阶段**）

用户口径：「根据主菜单各个分区与按钮的比例关系，重新跑一遍其他页面的窗口大小比例与字号大小」。

- 详细方案见 **`docs/UI比例基线方案-从主菜单反推-2026-10-21.md`**
- 核心：新增 `scripts/ui/eve_ui_metrics.gd`（纯静态函数，桌面端直通旧常量），
  把字号 T1~T4、控件 C1~C4、侧列宽统一绑到「屏高 / 屏宽」比例上。
- 三处待拍板：侧列宽（400 / **321** / 242）、顶条是否加高、HUD 战内字号能否到 T2。
- ⛔ 桌面端逐像素不变；⛔ 不新增 i18n key。

> 阶段 0 完成后再进入下面的 A~E；其中 B/D 的「尺寸与字号」直接改用阶段 0 的刻度。

### 阶段 A · 量现状（不改代码）✅ 下一步做这个

- 无头探针量 **ddz 牌桌**在手机设计空间（`1784×800`）下：
  各按钮命中矩形实际尺寸、手牌排布是否出屏、是否压底
- 量 **结算页 / 事件页** 内容最小高度（**1.20 字号档**）
- 产出：实测数字表，追加到本文档 §1

### 阶段 B · 斗地主手机档（几何 + 触控）

- 牌桌几何拆成「桌面基准区 / 手机档」两套口径（单一真相源，仿 `EveLayout.design_space()`）
- 自绘按钮：圆角 8 → **0**；热区 **≥88×48**；主操作（出牌 / 开始）高 **≥48**
- 左安全区避让（对齐 `MOBILE.safe_rect()`）
- 桌面 `1920×1080` 逐像素不变

### 阶段 C · 斗地主信息架构简化

- 按钮分组：**对局操作**（出牌 / 提示 / 托管） vs **系统**（设置 / 返回）
- 「样式」入口（`ddz_style_tune.gd`）合并或降级 —— 主界面入口过多是本轮要解决的问题
- 叫地主 / 抢地主状态区更明确（当前靠 toast）

### 阶段 D · 守卫边境收尾段手机档

- 结算页 / 通关页：内部按手机档排版（大字号、按钮 ≥48）
- 事件四选一：卡片触控热区 ≥88×48
- 与 `mobile_rects` 的 `result` / `event` 矩形对齐：**不重叠、整扇在屏内**

### 阶段 E · 验收 + 真机

- `verify_ddz` 增手机档断言；`verify_ddz_net` / `verify_ddz_online_ui` 必跑（联机共用牌桌）
- `tools/run_verifies.sh` 18 套全绿
- 导出 APK → 真机安装 → `pm clear` → 启动 → 截图核对
