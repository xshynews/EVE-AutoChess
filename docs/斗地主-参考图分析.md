## 二、值得抄（按性价比排序）

### A. 立刻可做（改动小、收益大）

1. **★★ 结算亮牌** —— 图 7/8 把三家剩下的牌**全部翻给你看**。
   现在我们的结束横幅只有一句「地主 胜 —— 你输了」。玩家**不知道自己差在哪**，
   也就学不到东西。⇒ 结束时把所有手牌摊在各自出牌区。

2. **★ 结算显示金币增减（飘字）** —— 每个座位头顶 `−2236 / +4089`。
   我们连「分差」都没有 ⇒ 一条 `±N` 就够（依赖代币，见 §四）。

3. **★ 叫分阶段的「牌局信息」给全** —— 图 1 里底牌（牌背）、剩余张数、
   手牌全亮，**该看的都在**。（本轮已修：叫分阶段原本把玩家的牌藏起来了。）

4. **新牌入手的「抬起」提示** —— 图 2 两张新底牌抬起来。
   我们底牌是直接混进手牌排序的，**玩家不知道哪三张是刚进来的**。
   ⇒ 地主确定后，把 3 张底牌在下一次重画时高亮 2 秒。

5. **对手动作用大字浮在头顶** —— 图 2「不抢」、图 4「不出」。
   我们放在出牌托盘的左上角小字（12px）。⇒ 对手的动作文字**放大**，
   浮在座位旁边（他们那边本来也空）。

6. **手牌排序按钮** —— 右下角「排序」。现在是固定按点数升序，
   玩家常想「大牌在前」。★ 我们**没有排序功能**（一个布尔 + 一个比较器）。

### B. 需要先定设计

7. **★★ 记牌器** —— 图 3 那个 14 格横排。
   ★ 我们**已经有数据**（`ddz_eval.unseen_counts`），现在只在顶部写了一行
   「外面还有：2×3 王×1」。做成图形化很容易。
   ⚠️ **但这是难度开关**：给玩家看记牌器 = 大幅降低难度（欢乐斗地主只在
   新手场给，高级场靠玩家自己记）。⇒ 要么做成**可开关**，要么只给「王和 2」。

8. **★★ 倍数系统** —— 见 §四，这是「代币」的发动机。

9. **明牌** —— 图 3 有「明牌」按钮（亮牌换倍数）。我们没有，属于加分项。

10. **结算的胜负大字 + 人物表情** —— 图 7/8 中央大字配卡通人物。
    我们有结束横幅（24px 文字），偏弱。⇒ 可放大 + 加几何图形（⛔ 不画人脸素材）。

### C. 不做 / 不该抄

| 项 | 为什么不做 |
|---|---|
| 照片级城市天际线背景 | 我们是 EVE 冷色 HUD，风格冲突；且要占包体 |
| 人物立绘（大图） | 版权 + 包体 + 风格。★ 头像位改由**几何剪影占位**，素材以后另想（见 §五） |
| 充值 / 储豆罐 / 看广告 | 我们是单机 |
| 那种高饱和暖色按钮 | 与现有 HUD 配色冲突（我们的强调色是青） |
| 桌面高对比蓝色椭圆 | 我们已定「桌面弱化存在感」（资料结论：专注打牌本身） |

## 四、代币体系：我的考虑（★ 这是当前最大的缺口）

### 结论：对，必须有。但**不能和自走棋的星币共用**。

**为什么必须有**：现在一局斗地主打完只有一句「你赢了」——
**没有代价、没有积累、没有目标**。自走棋之所以有"重量"，是因为有星币
（买船/刷新）和信标 HP（输了扣）。斗地主现在是**空转**。

**为什么必须分开**：星币是自走棋的**局内经济**，它的数值是按「每节点 3~6 星币」
这个量级平衡的。斗地主一局输赢动辄几百上千（参考图：+4089 / −4304），
两种量级混在一起，**会把自走棋的经济平衡冲垮**。

### 三个必须定的决策

**① 叫什么**
- `ISK`（EVE 通用货币）—— 最贴题材，但和 EVE 的"钱"绑得太紧
- `信用点` / `筹码` —— 中性，适合"游戏内小玩法"的定位
- ⇒ 我倾向 **ISK**，因为它一眼就是"这个世界的钱"，不需要新造词

**② 输了会不会"输光"**（最容易翻车的一条）

欢乐斗地主靠**充值**兜底；我们单机不能这么做。三个选项：

| 方案 | 说明 | 风险 |
|---|---|---|
| **A. 纯记分** | 只累计「净胜 / 连胜」，不设底金 | 最安全，但没有"赌"的紧张感 |
| **B. 底金 + 破产保底** | 输光后每日补满 / 打一局自走棋补 | 有紧张感，要写保底规则 |
| **C. 底金 + 自走棋产出** | ★ 打自走棋赚 ISK，拿去斗地主 | 最有意思（把棋牌室变成自走棋的副玩法），但要把两套数值接起来 |

⇒ **我的建议：先做 A，但字段按 B/C 设计**。
A 的实现只是「记录 + 显示」，不涉及任何数值平衡；等你看过实际手感，
再决定要不要加"输光的痛感"。而且 A 可以无损升级到 B/C（代币字段一样）。

**③ 倍数怎么算**

参考图的核心机制是：`结算 = 底分 × 倍数`，其中
- **底分** = 叫分（1/2/3）
- **倍数** = 2^(炸弹 + 王炸个数) × (春天 ? 2 : 1) × (明牌 ? 2 : 1)

★ **这个机制值得抄**，因为它把「叫分」和「扔炸弹」都变成**有代价的决策** ——
我们现在叫分只是个数字，没有任何后果。

⇒ 最小实现：`ISK 变化 = ±(底分 × 倍数 × 10)`。

### 建议的落地节奏

| 步 | 内容 | 依赖 |
|---|---|---|
| **第一步（很小）** | 代币**显示** + 每局结算加减 + 累计净胜 | 需定 §四① 名称 |
| 第二步 | 倍数系统（炸弹/春天翻倍）+ 结算飘字 | 第一步 |
| 第三步 | 底金与保底（方案 B/C）、自走棋兑换 | 你看过手感后再定 |

## 五、头像素材的几条路（供参考）

| 路子 | 做法 | 代价 |
|---|---|---|
| **几何占位（当前）** | 剪影（头 + 肩） | 零成本，但"没有脸" |
| **EVE 官方素材** | 从解包资源里找**角色头像/立绘**（EVE 有角色肖像） | 需筛选 + 裁方 + 注意风格（太空风 vs 牌桌） |
| **自走棋派系徽章** | 用 4 派系的 logo 当头像 | ★ 已有一套现成资产、风格统一、零版权风险 |
| **玩家自选** | 给一组几何/符号让玩家挑 | 便宜，但没个性 |
| 生成式 | 用图像生成做一组头像 | 风格统一难；成品发布要注意来源 |

⇒ 我倾向**先用「派系徽章」**（如果有现成的），它一次解决"风格统一 + 零版权 + 零成本"；
接口已经留好，随时能换。
