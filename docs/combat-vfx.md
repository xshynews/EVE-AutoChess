# 战斗视效与音效

本次修改沿用主菜单和正常对局入口，接入四类主武器、持续电子战、受击和击毁表现，以及选定的界面与武器音效。

## 武器与受击

- 激光炮使用金白束心、柔光和独立端点白闪，具有短暂升功率、维持和收束阶段；关束后的光点沿路径减速消散。
- 混合炮的束心、电弧和命中闪光共用固定的 0.14 秒传播时间，不再随射程变慢；余电沿经过的空间路径消散。
- 射弹炮使用实体热弹头、短曳光、辉光和炮口爆轰。
- 炮类按舰船吨位从不同原生挂点发出 2／3／4 发，挂点间隔 0.075 秒。
- 导弹每轮三枚，间隔 0.18 秒，从不同挂点侧向推出、点火并加速；实际抵达时结算伤害和爆炸。喷流、分焰及最亮辉光分别控制起势，爆炸不带暗烟。

武器来源使用原生舰体挂点。命中根据真实伤害结果选择曲面盾片或舰体接触点；未命中弹道从舰旁掠过并延伸出画面。远景尺寸补偿保留可读性，并限制放大倍率。

`EveBattleSimulator.attack_resolved` 发布实际伤害、受击层和破层事件，经 `EveBattleArena.fx_attack` 驱动武器及接触反馈，再通过 `attack_presented` 驱动血条与伤害数字。护盾平时透明，受击提亮对应的既有曲面片；破盾、破甲和击毁使用图标配合一个实际伤害总数，不叠加文字标签。舰体发光、血条辉光、损失段回收和数字运动统一跟随暂停及倍速。

击毁表现包含末击发光、错时殉爆、热裂烧蚀和慢速漂移碎片。活舰与残骸使用独立材质状态。

## 持续电子战

锁定压制以金色指向连接和舰体接收场表示，ECM 使用紫红干涉场。关系、强度、禁火时长及解除均读取模拟器状态；表现不额外掷骰、不延长作用时间，也不触发武器受击反馈。

## 无人机视觉组件

保留七种原 EVE 候选舰体、贴图和原生喷口目录，以及三机离舰、平滑高速掠袭、提前侧倾、返航、分阶段推进器、短尾迹、机体能量层、紫白射弹和接触碎光。开火前不显示红色引导线。

调用 `EveBattleFx.deploy_drone_squadron(source_visual, target_visual, model_index)` 可播放整组演出；候选目录位于 `assets/vfx/combat/drones/drone_models.gd`。演出沿用武器特效的暂停、倍速和远景尺寸补偿。无人机射弹使用独立的有限弹段路径，主武器表现不受影响。

这部分保留为后续接入使用的视觉组件，目前没有修改正式对局的部署、寻敌、转火或伤害规则。模型与贴图来源随各候选目录的 `sources.json` 保留。

## 声音

`EveUiAudio` 统一播放语义化的界面和阶段声音；同一操作有明确语义反馈时，通用点击声不重复播放。播放器跨窗口和场景保留，继续使用原有 Master、SFX 和 Ambience 音量设置。选音与播放增益位于 `assets/audio/ui/selection.json`，没有槽位提示、播放历史或试听设置界面。

`eve_weapon_audio.gd` 按舰船吨位选择短尾音素材，逐发绑定实际发射与导弹命中时机，不通过改变音高区分吨位。中档混合炮无蓄能；中档激光的蓄能声读取既有武器冷却，在正式开火前播放，打断和目标失效时停止，不改变战斗规则。同一档位完全相同的音频只保留一份。

资源来源和声音映射分别记录在 `assets/vfx/combat/sources.json`、相关素材目录的 `sources.json`、`assets/audio/ui/selection.json` 和 `assets/audio/weapons/sources.json`。运行及完整导出不依赖本机 EVE／HD2 安装路径、邻仓或提取工作目录。

## 提交范围

提交包含正式游戏调用的实现与素材，以及保留供后续接入的无人机视觉组件。独立模型对比页、技能蓄能、物理特效试片、试听工作台、录屏脚本及临时检查工具不属于这次发布。

新增 JSON 配置已加入完整导出的包含列表；首次交付这些新增资源应使用完整构建。
