## 二、这一版玩家能感觉到什么（相对 b26 的改动）

炼狱难度「黑市情报 → 抽奖窗」的规则修正：

1. **合并单池**：一星池（cost≥3，32 艘）+ 二星巡洋池（12 艘）**合为一池 44 艘**，
   不再分两个池子各抽一次。
2. **一次只抽 1 艘**：`LOTTERY_DRAW_TIMES = 1`。b26 是抽 2 艘，奖励过厚，已收回。
3. **许愿仍保留**：玩家可从全池选 1 艘许愿（按 ship_key + star 精确匹配；
   同一艘船的一星 / 二星是两张不同的许愿卡）。抽到许愿舰即返该船**一星价格**的星币
   （二星也按一星计价，返 3）。
4. 二星不另建数值表：`entry.star` 走 `STAR_MULT^(n-1)`。

开战运镜、主力晚压、炼狱经济补偿等 b26 内容**不变**，本次只动抽奖。

## 三、发版流程（本次实操）

1. `export_presets.cfg` `version/code` 26 → 27（工程内仅此一处 `version/code`）。
2. `tools/publish_hotfix.sh` 导出 → 剥 icudt（5.70MB → 1.04MB）→ SHA256 →
   写 `build/version.json` → 上传 pck 到 GitHub Release。
3. `build/version.json` 作为附件挂到同一 Release（服务器拉清单用）。
4. 源码 `c5b84cb`（合并池）+ `486a9fd`（抽 1 艘）+ `29742c5`（code 升 27）
   推到 `origin/main`。
5. 服务器（lighthouse 通道）：
   - 备份 `version.json` → `version.json.b26`
   - `curl` 从 gh-proxy.com 拉 pck → 对 SHA256 一致（074a6d70…ac18）
   - 拉 `version.json` 落盘，`chown www-data:www-data`
6. 本机公网验收：清单 code=27、pck 200/1095161B/1.9s、Range 请求 206。

⚠️ 导出时 Godot 顺手把 `project.godot` 里的 `MCPRuntimeProbe` 自动加载项删了，
那是 Godot MCP 插件读工程用的，已 `git checkout` 回退，未进提交。
