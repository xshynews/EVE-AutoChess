## 3. 跑探针（验证的标准入口）

**统一用包装脚本，不要直接敲 Godot 命令：**

```powershell
& "C:\Users\Administrator\.workbuddy\binaries\python\versions\3.13.12\python.exe" `
  C:\godot\_run_godot.py res://tools/<探针>.tscn --window --quit 8000 `
  --report C:\godot\_export\_reg\<报告>.txt
```

| 参数 | 作用 |
|---|---|
| 位置参数 | 探针场景路径（可以不是主场景） |
| `--window` | **带窗口跑**。读 `vp.get_texture().get_image()` 的探针**必须**加，否则无头下永远等不到 `frame_post_draw`，脚本挂到 `--quit-after` 用尽，报告里什么都没有 |
| `--quit N` | tick 上限。**必须给** —— 脚本一旦报错就会永久挂起（实测挂过 2 分半） |
| `--report 路径` | 报告落盘路径 |

### 3.1 探针清单与下限

| 场景 | 断言数 | 需 `--window` |
|---|---|---|
| `tools/test_layout.tscn` | 414（下限 406） | 否 |
| `tools/probe_r5_orbit.tscn` | 57 | 否 |
| `tools/probe_r5_input.tscn` | 49（下限 38） | **是** |
| `tools/probe_r3_cam.tscn` | 51 | 否 |
| `tools/probe_r3_ships.tscn` | 34 | 否 |
| `tools/probe_r3_plate.tscn` | 28 | **是** |
| `tools/probe_drop.tscn` | — | **实拖用例必须** |

### 3.2 判定「过了」要三件一起

只看退出码会**被骗**：`Parse Error` 时脚本整个不加载，
`--quit-after` 仍然返回 `EXIT=0`，报告里只剩上一轮的残留内容。

```
① 新报告确实被覆盖（看文件时间戳）
② grep 报告里没有 SCRIPT ERROR / Parse Error
③ 报告末尾「0 异常」且「断言执行数 N」≥ 下限
```

> **探针必须报「断言执行数 N」**，用 `MIN_CHECKS` 下限兜底。
> 否则「提前 return 掉一大片」会被读成通过。

## 4. Godot 命令行脚本的坑（踩过的，别重踩）

### 4.1 类型推断

```gdscript
var x := load("res://scenes/board.tscn").instantiate()
# ✗ Parse Error: Cannot infer the type（load 返回 Variant）
var x: Control = load("res://scenes/board.tscn").instantiate()   # ✓
```

### 4.2 类型化变量不能调私有方法

```gdscript
var b: Control = ...
b._foo()          # ✗ 解析失败
var b: Variant = ...   # ✓ 要调私有方法就用 Variant
```

### 4.3 播种必须在 autoload 之后

autoload 的 `_ready()` 早于主场景脚本 —— 在脚本开头 `seed()` 管不到 autoload 里摇出来的状态。
要在主场景实例化后**重新 `seed()` 并把随机状态重摇一遍**，否则同种子跑出不同结果。

### 4.4 无头等 N 秒用标量推进，不用 Timer

Godot 的 Timer 每帧最多触发一次，比标量慢三个数量级。
想「自动玩一局」就把驱动逻辑写成一个 Node 场景，直接调私有 tick 函数按需推进。

### 4.5 `%` 格式化不支持 `%.2e`

运行时 `String formatting error`，不是解析错。只用 `%s / %f / %d`。

### 4.6 一批 tool call 里不要对同一文件发两个 Edit

后写入的版本会覆盖前一个，两个编辑只生效一个。同文件多次编辑**必须串行**。

## 5. 已知本机环境问题

| 问题 | 处置 |
|---|---|
| **Bash 的 PATH 损坏**（`dirname` / `ls` / `head` 全 command not found） | 退化方案：全程 PowerShell，stdout 重定向到文件再 Read |
| **PowerShell 捕获原生 stdout 中文会烂** | 走 `_run_godot.py`，读落盘文件判红绿 |
| **`Remove-Item` 被 safe-delete 守卫拦下** | 临时文件删不掉就告诉用户手动删，别反复重试 |
| **`Add-Type` 被安全策略拦截** | 想读 ZIP 用 Python 的 `zipfile`（stdlib） |
| **git 不在 PATH** | `C:\Users\Administrator\.workbuddy\binaries\PortableGit\versions\1.2.0\cmd\git.exe`；仓库未配 user.name/email，提交要带 `-c user.name="..." -c user.email="..."` |
| **PowerShell 5.1 里 `foreach (...) { } \| Out-File` 是语法错误** | 收集到 `List[string]` 再一次性 `Out-File` |
